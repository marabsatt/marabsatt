I'm Mitch Rabsatt, a Data Scientist and AWS Certified Solutions Architect focused on designing scalable AI/ML, GenAI, RAG, and MLOps solutions.

My work sits at the intersection of machine learning, cloud architecture, data platforms, and business facing analytics. I build systems that move beyond experimentation: cloud data pipelines, model deployment workflows, REST APIs, monitoring patterns, and stakeholder-facing applications that turn data and AI into usable products.

This GitHub serves as my technical portfolio for AI/ML Solutions Architecture. I use it to document reference architectures, implementation patterns, and applied projects across AWS, Databricks, MLOps, generative AI, and cloud native data systems.

Current focus areas:

- AI/ML Solutions Architecture
- GenAI and Retrieval Augmented Generation
- MLOps and LLMOps
- Cloud native data platforms
- AWS architecture and Terraform based reference implementations
- Production oriented ML workflows
